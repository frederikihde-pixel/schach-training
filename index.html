Wo die Daten liegen

Alle Daten bleiben nur in diesem Browser auf diesem Gerät. Es gibt keinen Server und kein Konto. Benutze deshalb immer denselben Link zur App: Die Daten gelten pro Adresse. Ein anderer Link oder ein anderer Browser hat einen leeren Speicher.

Diese Adresse:

Auf dem iPhone kann Safari die Daten von Seiten, die nicht auf dem Home-Bildschirm liegen, nach längerer Pause löschen. Installiere die App und sichere die Daten regelmäßig.

Über diese App

Schach-Training ist eine kleine Trainings-App für Freunde. Sie läuft vollständig im Browser. Es gibt keinen Server, alle Daten bleiben auf diesem Gerät. Der Quellcode steht unter der GNU General Public License, Version 3 (GPL-3.0).
